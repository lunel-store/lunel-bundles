Local demo

Start the bundled static server from the repository root (it serves the root so /demo/… and /assets/… resolve just like production). Opening file:// will not work. 

cd /path/to/lunel-bundles
node demo/serve.js          # http://localhost:8080/demo/
# or a custom port:  node demo/serve.js 3000

No dependencies required — it uses Node's built-in http module. (If you prefer Python: python3 -m http.server 8080 from the repo root also works.)

Then open each product page — every page shows exactly three bundles:

  • Product 1822939513 — مجموعة لونيل المتكاملة (bundles 1 · 2 · 3, three badges on card 3)
  • Product 922735217 — مجموعة العناية الأساسية (bundles 4 · 2 · 3)
